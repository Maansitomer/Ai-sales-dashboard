# 🛍️ AI-Powered Sales Trends Intelligence Dashboard

An interactive **Streamlit dashboard** that leverages **machine learning** and **real-time sales data** to help businesses make smarter pricing and discounting decisions.  
Unlike static tools like Excel or Power BI, this project acts as an **AI assistant for decision-making** — providing predictive insights, dynamic recommendations, and negotiation-ready pricing.

---

## 🚀 Features

- **🔮 Price Prediction**  
  Predicts the **optimal selling price** for any product based on cost, profit margin, demand index, customer age, season, payment method, and more.

- **📊 Interactive Dashboard**  
  Explore sales trends using **15+ interactive filters** (brand, season, payment method, age, quantity, etc.) with live visualizations.

- **📈 Dynamic AI Insights**  
  Automatically generates **business insights** from the filtered data (e.g., high discounting trends, premium pricing behavior, return rates, seasonal demand).

- **🧠 AI-Powered Negotiation Tool**  
  Assists sales teams in **customer negotiations** by suggesting data-backed, competitive price points instead of relying on guesswork.

- **📉 Visualization Suite**  
  Includes distribution plots, seasonal and category-based trends, and top-performing brands/categories.

---

## 🛠️ Tech Stack

- **Frontend:** [Streamlit](https://streamlit.io/)  
- **Data Analysis & ML:** Python (Pandas, NumPy, scikit-learn, joblib)  
- **Visualization:** Matplotlib, Seaborn  
- **Model:** Random Forest Regressor trained on multiclass clothing sales dataset  

---

## 📂 Dataset

- **File:** `Multiclass Clothing Sales Dataset.csv`  
- Contains sales transaction data including **brand, season, payment method, quantity sold, discount %, return rate, demand index, and customer demographics**.
